# Susejing Themes

Temas de marca **Susejing** para [Kino](https://kinotvapp.github.io/kino-plugins/).

## Instalación

**Ajustes → Plugins → +**

```
Susejing/Susejing-Themes
```

Luego: **Ajustes → Apariencia**, o abre la pantalla **Temas** del plugin.

## Temas incluidos

| Id | Nombre |
|----|--------|
| `susejing-night` | Susejing Noche (violeta) |
| `susejing-sakura` | Susejing Sakura (rosa) |
| `susejing-cyan` | Susejing Cian |
| `susejing-ember` | Susejing Ascua (naranja) |

Cada uno permite ajustar el acento y el fondo en Apariencia ▸ Personalizar.

## Limitación

Kino solo acepta temas definidos en el manifiesto (máx. 8). No se puede aplicar una imagen aleatoria de internet como fondo de la app.
